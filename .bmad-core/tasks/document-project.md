# Task: document-project

## Purpose
Perform a comprehensive documentation pass of the entire project, producing or updating all standard BMAD documents.

## Steps
1. Read the project structure and existing documentation
2. Identify which standard documents are missing or outdated:
   - Project Brief
   - PRD
   - Architecture Doc
   - Tech Stack doc
   - API Spec (if applicable)
   - Test Strategy
   - Deployment Guide
3. For each missing document, create it using the appropriate template
4. For each outdated document, update it to reflect current reality
5. Produce a documentation index at `docs/README.md`

## Output
All documents written to `docs/` with an index file.
